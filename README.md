# تطبيق إدارة طلبات الشراء والمشتريات (Procurement App)

تطبيق متكامل مبني باستخدام Flutter لإدارة طلبات الشراء وتوليد أوامر الشراء وطباعتها مباشرة بصيغة PDF.

## محتويات المشروع:
- `assets/seed_data.json`: قاعدة بيانات الأصناف والقوائم المستخرجة من شيت الإكسيل.
- `lib/database_helper.dart`: محرك قاعدة البيانات المحلية SQLite.
- `lib/new_order_screen.dart`: شاشة إدخال وترحيل طلب الشراء وحساب الإجماليات.
- `lib/order_printer.dart`: محرك طباعة وتصدير أمر الشراء A4 PDF.
- `lib/main.dart`: الشاشة الرئيسية واستعراض الطلبات المرحلة.
- `.github/workflows/build_apk.yml`: سكريبت التجميع السحابي التلقائي لاستخراج ملف الـ APK.
